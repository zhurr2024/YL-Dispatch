# YL-Dispatch

全虚构浏览器交互演示，无真实登录、企微鉴权或后端；请勿输入真实资料。

## 在线入口
- PC：[工作概览](https://zhurr2024.github.io/YL-Dispatch/#/overview)
- H5：[移动工作台](https://zhurr2024.github.io/YL-Dispatch/#/h5)
- 入口需 GitHub Pages 部署成功；Vite base 为 `/YL-Dispatch/`，使用 hash 路由。

## 演示角色切换
1. PC 右上角选择模拟销售，自动进入 H5；H5“切换身份”用于销售之间切换。
2. H5 右上角或“我的”点击 **返回 PC 工作台**。
3. 在 **选择管理员身份，返回 PC** 中选择现有系统管理员或业务运营，先切换身份再返回概览。
4. 系统管理员恢复已有系统功能，运营保留已有品类授权；取消不改变身份。已为管理员的 H5 欢迎页可直接返回。

返回不重置本地线索、派发、认领、反馈和订单，刷新仍保留所选身份。
同源 PC/H5 窗口及 `/mobile` 内嵌预览共享身份；切换会同步影响其他窗口。
预览仅导航当前框架，不跳转顶层窗口；恢复管理员后可在外层 PC 继续操作。
这只是模拟身份选择，不新增权限，也不构成真实授权或安全边界。

## 开发与验证
Node.js 22：`npm ci`、`npm test`、`npm run build`；本地预览使用 `npm run dev`。
测试覆盖业务规则、部署路径及实际 SFC 返回处理器（mock Vant/路由入口、真实 store/内存路由）；
浏览器点击、布局和跨窗口体验仍需人工验收。

本仓库仅包含独立虚构种子，不含本地原应用的工作簿样本、原始文档或需求背景目录。
公开存储键 `yili-public-demo-v1` 与本地原应用隔离。详细说明见 `README.txt`。
